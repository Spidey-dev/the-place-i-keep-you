# The Place I Keep You

A private, cinematic love-letter website built as a single static page.

## Quick start
Open `index.html` in a browser.

## Personalize
Search the HTML for sample relationship details and replace them with your real memories, dates, photos, audio, and her name.

## Deployment
Works as a static site on GitHub Pages, Vercel, Netlify, Cloudflare Pages, or any standard web host.
